# youtube_player_darwin

The iOS and macOS implementation of [`youtube_player`](https://pub.dev/packages/youtube_player). It hosts the YouTube IFrame Player API in a minimal `WKWebView`, written in Swift 6 and driven over Pigeon, and uses WebKit's element fullscreen.

## Usage

This package is [endorsed](https://flutter.dev/to/endorsed-federated-plugin): depend on `youtube_player` and this implementation is included automatically.
