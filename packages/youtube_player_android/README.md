# youtube_player_android

The Android implementation of [`youtube_player`](https://pub.dev/packages/youtube_player). It hosts the YouTube IFrame Player API in a minimal `android.webkit.WebView` driven over Pigeon, and uses the WebView's custom-view fullscreen.

## Usage

This package is [endorsed](https://flutter.dev/to/endorsed-federated-plugin): depend on `youtube_player` and this implementation is included automatically.
